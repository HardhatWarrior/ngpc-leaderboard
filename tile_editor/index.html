Scale (Resample)

Resamples the pixel art itself to a new tile size (nearest-neighbor — an approximation, since palette-index art can't blend like real color can). Works on the selection if you have one, else the whole canvas. Clears per-tile palette overrides in the affected area, since tile positions no longer line up with the original art.

Tools

No selection — actions apply to whole canvas.
Left click/drag = primary color. Right click/drag = secondary. Right-click while Select is active clears the selection. Click-drag inside an existing selection to move it (snaps to whole tiles) instead of redrawing it.

Shapes

Drag on the canvas to draw. Left = primary color, right = secondary. Hold Shift while dragging Rect/Ellipse for a square/circle.

Magic Wand

Click with the Wand to select a same-color blob on the active layer. Ctrl+click adds another blob to the selection. Click-drag inside the selected pixels to move them freely (no tile snapping). Copy it, then Paste stamps just those pixels elsewhere — everything else at the destination stays untouched (right-click cancels a pending paste or clears the wand selection).

Transform

With a selection: rotates/flips just that region on the active layer. With no selection: rotates/flips every layer together (whole tileset geometry).
Requires a selection. Leaves the original alone and loads a mirrored copy into the Paste tool — click the canvas to place it wherever you like.

Slide (wrap)

Shifts pixels on the active layer by 1px per click (Alt+Arrow keys work too); pixels that fall off one edge reappear on the opposite edge. Works within the selection, or the whole canvas if none.

Palette Bank

All banked palettes export together as one shared project palette table. Each layer picks a default palette (dropdown in Layers); individual tiles can override it below. "Remove Unused" drops every bank palette that no layer's default or per-tile override currently references.

Tile Palette Override

Select tile(s) with the Select tool, then assign a bank palette to just those tiles — the pixel art (index data) stays shared with the rest of the layer, only the palette attribute changes. This matches how NGPC tilemaps really work (palette is a per-cell attribute, not baked into the bitmap).

Tile Groups (Named Sub-Regions)

Select tile(s) with the Select tool, name them, and Add — the group's tile-index range and a ready-to-use index array get emitted in the C output. Great for marking sprite-sheet animation frames (walk_up, walk_down, idle_left, etc.) without hand-counting tile indices. Groups belong to the active layer and are shown as labeled dashed boxes on the canvas.
Adding a group with a name that already exists on this layer replaces it with the current selection's bounds. Groups are clamped to stay inside the grid automatically if you resize/crop/scale afterward — recheck them if you do.

NGPCraft C Output
Refreshes automatically as you edit. Each layer emits its own row-major (left→right, top→bottom) u16 tile array (8 words/tile, 2bpp MSB-first — matches this project's existing art.c/*_mspr.c format) plus a per-tile palette-index array. Palette words are hex literals (R | G<<4 | B<<8) — safe from the raw RGB() macro's blue-channel truncation bug on cc900.
