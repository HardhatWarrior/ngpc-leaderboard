About

A per-pixel true-color canvas -- every pixel independently picks any of the 4096 real RGB444 colors (4 bits/channel), with none of the Tile Editor's per-tile 3-color-plus-transparent hardware limit. Not meant for real NGPC tile/sprite hardware -- this is a reference/asset tool, e.g. for painting an avatar for the hiscore site's avatar maker, which uses the exact same color model and can import a saved project from here directly.
