Tools

Stamp/Erase place the whole selected tile block. Fill and Eyedrop always work on a single cell (Fill uses just the block's top-left tile). Select: drag to define a rectangle, drag again from inside it to move its content. Sprite: click empty space to place a preview-only sprite from the current stamp block, drag an existing one to move it.

Map Layers

Always exactly Layer 1 and Layer 2, regardless of how many tileset layers are imported. Assign each one to SCR_1 (back) or SCR_2 (front) with its dropdown -- each cell also remembers which tileset layer its tile came from. The 3rd row, Sprite Plane, is fixed to SPR_PLANE and can't be reassigned -- click it to switch to the Sprite tool below and place preview sprites for reference.

Sprite Preview Layer

Preview only -- placed sprites are not included in the C export. Uses whatever tile block is currently selected in the Stamp panel. Sprites are a free-floating list, not a grid, so they can overlap each other and the map without erasing anything.

Map Size (tiles)

x
Grows/crops from the top-left. The real SCR1/SCR2 VRAM window is only 32x32 tiles at once — a bigger map means streaming rows/columns in at runtime as the camera scrolls.

Hardware Budget

Character RAM holds 512 tiles total (shared by every layer + sprites); slots 0-31 are hardware-reserved and 32-127 are the BIOS font, so budget against ~384 free. Each plane also has its own 16-palette budget.
