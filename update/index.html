SAVE UPDATER

Carry your save from an old build of any of our games to a new build of the same game, multipacks included.

Getting your save off the cart

  1. Put the flash cart with your old build in your flasher.
  2. Read (back up / dump) the whole cart to a file with your flasher's software. The save lives inside the ROM image, so a full read is all you need (2 MB, or 4 MB for the 5-course Turf Masters build).
  3. Pick that file as the old ROM below, and the new build of the same game as the new ROM.

Update

Everything runs in this browser. Nothing is uploaded.

How it works

Our games keep their save in the cart's save area (the 16 KB at 0x1F8000-0x1FBFFF). The updater copies that area from your old cart into the new build unchanged, so the new build finds the save exactly as if the cart had been updated in place, and upgrades it if the save format grew. Use builds of the same game (or the same pack): a save carried into a different game is ignored, or wiped by it. GUARDIANS OF THE NOCTURNE has its own updater with more options: /gn/update/.
