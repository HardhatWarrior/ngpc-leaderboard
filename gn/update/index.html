SAVE UPDATER

Carry your save from an old build to a new one, back to nocturne_01, FILE 1-3 included.

Checking access…

Getting your save off the cart

  1. Put the flash cart with your old build in your flasher.
  2. Read (back up / dump) the whole cart to a file with your flasher's software. The save lives inside the ROM image, so a full 2 MB read is all you need.
  3. Pick that file as the old ROM below, and the fresh new build as the new ROM.

Update

Everything runs in this browser. Nothing is uploaded.

What carries over

nocturne_19 and later: the whole save as it is (tale, map, QUIT & SAVE spot, settings, MUSIC ROOM, BESTIARY). Older builds had FILE 1-3: the file you pick becomes the tale and the new build converts it on load, exactly as if the cart had been updated in place. nocturne_12-18 files keep their land map and their QUIT & SAVE spot. nocturne_01-03 files start at CODA's gate (those builds used an older, smaller world map), and a nocturne_01-02 file gets an OAK STAFF and CLOTHES with its herbs in the bag. A cart holds one tale, so the other files are not carried: write down their TALE CODEs in the old build first if you want them.
