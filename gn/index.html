Put it on the completion board

Your initials, completion, badges and furthest journey go on the public board below (one entry per account; it only changes when a code ranks higher). Sign-in required.

How it is counted: completion % is the weighted share of the badges (a journey 3, the finale 6, a tower climb 2, all tower bosses 2, all 30 artifacts 3, the whole BESTIARY 3, half of it 2, every other badge 1; the BESTIARY's share also counts entry by entry: 3 points spread over its 129 entries; 100% only when every badge is lit; the Secrets badges are for show and never count). A journey counts once THE SILENT KING is beaten on it (or a later journey began). The code carries no world map, only (since version 11) a FULLY CHARTED mark: MAP COMPLETE is that mark, or the SEXTANT the cartographer gives for a whole map. ISLANDS SETTLED = every island arrived (they all have by NEW GAME+ 5) and its quest done. EVERY CAUSE FUNDED is judged on the journey the code was made on (every city's cause at tier 3). The set titles, MASTER CURATOR and GUARDIAN OF THE NOCTURNE are the same badges as sets I-V, all 30 artifacts and COMPLETE. The tower is climbed on NEW GAME+ journeys 1-5.

Read your tale

Your whole adventure travels as a TALE CODE: on the cartridge open YOUR TALE › TALE CODE and either scan its QR with your phone's camera or type the code in here. The stats are worked out from the code right in your browser. If you are signed in, the code is kept on your account until you read a new one, so it follows you to any device; signed out, it is only remembered in this browser. Either way the code is private: only you can see it. Its ACHIEVEMENTS can go on the public COMPLETION BOARD below if you choose to submit them.

Completion board

Ranked by completion %, then badges, then whoever got there first. Read your TALE CODE in Your tale above and submit it to join. Tap a row for its badges.
