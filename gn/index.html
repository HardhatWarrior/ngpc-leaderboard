Read your tale

This game has no scoreboard. Your whole adventure travels as a TALE CODE: on the cartridge open YOUR TALE › TALE CODE and either scan its QR with your phone's camera or type the code in here. The stats are worked out from the code right in your browser. If you are signed in, the code is kept on your account until you read a new one, so it follows you to any device; signed out, it is only remembered in this browser. Either way it is private: only you can see it, and there is no public board.
