ACCESS GROUPS

Two groups for early access: Testers (you pick the members) and Developers (every account with developer access, current and future). Attach either group to as many games as you like. Members see an attached game even while it’s Coming Soon, the same as a per-game tester.

Members

Accounts in the group. They get no edit rights, only access to the games you attach below.

Developers

Automatic: every account with developer access is in this group, and new developers join it the moment you approve them. Change who is a developer from the user list on the Admin page.

Games

Tick which groups can see each game. Changes are saved together with the button at the bottom.
